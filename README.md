# Bodega Shekinah

## Aplicación de gestión para Bodega Shekinah

Esta aplicación será utilizada para administrar la bodega de forma sencilla desde el teléfono.

### Funciones principales

- 📦 Inventario de productos
- 🛒 Registro de ventas
- 💰 Precios de compra y venta
- 📊 Control de existencias
- 💵 Conversión de precios entre USD y Bs
- 🔎 Búsqueda de productos
- 📷 Escáner de códigos de barras
- 📱 Diseño adaptado para teléfonos
